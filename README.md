# Hatebu Domain Filter

はてなブックマーク([b.hatena.ne.jp](https://b.hatena.ne.jp/))の記事一覧から、
登録したドメインの記事を `display: none` で非表示にするChrome拡張機能です。

見たくないサイトを見つけたその場で、記事のドメイン名の横に出る「非表示」ボタンを押すだけで登録できます。

## 主な機能

- **ホバーして1クリックで登録**: 記事にマウスを乗せると、ドメイン名の横に「非表示」ボタンが出ます。押すとそのドメインが登録され、一覧上の同じドメインの記事がすべて消えます
- **取り消し**: 登録直後のトーストから「取り消し」で元に戻せます(誤クリック対策)
- **はてブ内の一覧すべてに適用**: トップ・人気エントリー(hotentry)・新着エントリー(entrylist)・カテゴリ別・検索結果に対応。無限スクロールで後から読み込まれた記事も非表示になります
- **設定画面**: 登録済みドメインの一覧・追加・削除、1行1ドメインの一括編集(バックアップ用のコピー/貼り付けもここで)、拡張機能全体のON/OFF
- **ツールバーアイコン**: クリックで設定画面を開きます。バッジに登録件数、OFFのときはアイコンがグレーになります

## インストール方法

Chromeウェブストアには公開していないため、開発者モードで読み込んで利用します。

1. このリポジトリをクローン、またはZIPでダウンロード
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をONにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このプロジェクトのフォルダを選択

## 使い方

### 一覧から非表示にする

はてなブックマークの記事一覧で記事にマウスを乗せると、ドメイン名(`example.com`)の右に
「非表示」ボタンが出ます。クリックするとそのドメインが登録され、一覧上の同じドメインの記事が
すべて消えます。画面右下のトーストから「取り消し」を押せば元に戻ります。

### 設定画面から登録・削除する

ツールバーのアイコンをクリック(または `chrome://extensions` の「拡張機能のオプション」)で設定画面が開きます。

- **ドメインを追加**: `example.com` のように入力します。記事のURLをそのまま貼り付けても、ドメイン部分だけを取り出します
- **一括編集**: 1行1ドメインのテキストとして編集できます。`#` で始まる行はコメントとして無視します。バックアップしたいときはこのテキストをコピーして保存してください
- **有効/無効**: 右上のスイッチで、登録を消さずに一時的にすべての非表示を解除できます

## 仕様メモ

- **ドメインは完全一致**: `example.com` を登録しても `news.example.com` は消えません。サブドメインごと消したい場合は、それぞれ登録してください
- **`/site/<ドメイン>/` のページでは非表示にしません**: そのドメインの記事一覧を自分で開いたページなので、非表示にすると真っ白になってしまうためです(このページでも「非表示」ボタンからの登録はできます)
- **対象は `b.hatena.ne.jp` のみ**: 記事のリンク先(外部サイト)には一切影響しません

## 開発

ビルド不要のプレーンなJavaScript(Manifest V3)です。

```
manifest.json
icons/              アイコン(icon.svg が原本、PNGはそこから書き出し)
src/lib/            ストレージとドメイン正規化(設定画面・content script・Service Worker共通)
src/scripts/        content script と Service Worker
src/options/        設定画面
test/e2e.js         実サイトに対するE2Eテスト(Playwright + Brave Browser Nightly)
```

E2Eテストの実行方法は `test/e2e.js` の冒頭コメントを参照してください。
